- Ollama = 학습 자료라기보다 "빠른 실습" 쪽입니다. README·quickstart·블로그 정도라 양은 적지만, "일단 돌려보는 체험" 자체가 입문 학습으로 좋습니다.
- HuggingFace = 여기가 진짜 공부 자료의 보고입니다. 단순 docs가 아니라 체계적 학습 콘텐츠가 많아요:
- HF Learn (코스): LLM/NLP 무료 강의 — 구조적으로 배우기 좋음.
- HF Blog: QLoRA·양자화·vLLM 서빙 등 주제별 how-to 글(당신이 말한 "정보글"이 이것).
- HF Docs: transformers·PEFT(LoRA/QLoRA)·TRL(파인튜닝) — 라이브러리 문서가 곧 튜토리얼.
- Cookbook: 실전 레시피 모음.
- 모델 카드: 모델별 실행법·VRAM·예시.

- r/LocalLLaMA (Reddit) — 로컬 LLM 셋업·GPU·모델 추천·양자화 실전의 사실상 본진. 당신처럼 "집 GPU에 뭐 올릴까"류 정보가 가장 많음.
- vLLM 공식 docs / recipes — 서빙 공부(앞 가이드에서 쓴 그 레시피 페이지).
- GitHub awesome-류 목록 (예: awesome-local-llm) — 자료 큐레이션.
- 유튜브/개인블로그의 5060 Ti·홈랩 LLM 셋업 가이드 — 하드웨어 구체 사례.
