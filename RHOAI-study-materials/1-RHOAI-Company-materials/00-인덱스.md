## Red Hat AI 큰 그림 (한 장 요약)

**Red Hat AI** = 하이브리드 클라우드 전반에서 예측형/생성형/에이전트 AI의 라이프사이클을 일관되게 구축·배포·관리하는 **포트폴리오**.

핵심 메시지: **"Any model, any accelerator, any cloud"** — 어떤 모델이든, 어떤 가속기든, 어떤 클라우드든.

### 제품 4종 (포트폴리오 구성)

| 제품 | 한 줄 정의 | 대상 |
|---|---|---|
| **Red Hat AI Inference Server** | vLLM 기반 최적화 추론 런타임 (단독 제품) | LLM 추론 최적화 |
| **Red Hat Enterprise Linux AI (RHEL AI)** | 단일 서버 환경용 파운데이션 모델 어플라이언스 (immutable RHEL 이미지) | 개별 Linux 서버 |
| **Red Hat OpenShift AI (RHOAI)** | 분산 Kubernetes 플랫폼용 통합 AI 플랫폼 (MLOps/LLMOps 전주기) | 분산/스케일 |
| **Red Hat AI Enterprise (RHAIE)** | 엔터프라이즈 AI 배포·확장용 통합 플랫폼 (OpenShift 기반) | 전사 확장 |

### 4대 가치 축 (모든 자료의 공통 골격)

1. **Flexible & efficient inferencing** — vLLM + llm-d + 모델 압축으로 빠르고 저렴한 추론
2. **Connecting models to data** — RAG, 파인튜닝, SDG, Llama Stack으로 사내 데이터 연결
3. **Agentic AI innovation** — Llama Stack(통합 API) + MCP로 에이전트 구축·운영
4. **AI at scale (hybrid cloud)** — GPU 풀링/MIG/Kueue, 관찰성, 거버넌스로 스케일

### 핵심 오픈소스 기술 스택

- **vLLM** — 고처리량 LLM 추론 엔진 (PagedAttention, continuous batching, speculative decoding). Red Hat이 핵심 컨트리뷰터(7명 코어 커미터), Neural Magic 인수.
- **llm-d** — Kubernetes 네이티브 분산 추론 프레임워크 (Red Hat·Google·NVIDIA·IBM·HuggingFace 공동). prefill/decode 분리, KV-cache 인지 라우팅.
- **LLM Compressor** — 양자화/sparsity 압축 툴킷 (99% 정확도 유지 목표)
- **KServe / LLMInferenceService CRD** — k8s 모델 서빙 표준
- **Llama Stack** (→ 신규명 ogx) — 통합 AI API 서버 (추론·RAG·에이전트·안전·텔레메트리)
- **MCP (Model Context Protocol)** — 에이전트-툴 연결 오픈 표준
- **Docling / SDG Hub / Training Hub** — 데이터 처리·합성데이터·학습 모듈

## 자주 나오는 수치/근거 (영업 토킹포인트)

- 모델 운영화에 **7~12개월**(50%) / **1년+**(26%) 소요 (Gartner 2023)
- AI 도입 조직 **89%**가 어떤 형태로든 오픈소스 AI 사용 (Linux Foundation)
- **2027년까지 AI 배포의 75%+**가 컨테이너 기반 (Gartner)
- 양자화: **8-bit ≈ 1.8x 가속(정확도 완전 유지)**, **4-bit ≈ 2.4x 가속** (Red Hat 50만+ 평가)
- 모델 압축: **GPU 시간 40%+ 절감**, **정확도 95~99% 유지**, HuggingFace 다운로드 **1,600만+**
- llm-d: SLA 제약 하 **베이스라인 대비 2배 QPS** (Llama 3.1 70B FP16)
- vLLM + 압축: **추론 성능 최대 4배**, GPU 요구량 절감(예: 8→2)
- Gartner: 2029년까지 에이전트 AI가 **일반 고객서비스 이슈 80% 자율 해결**, 운영비 30% 절감
- Gartner: 2027년까지 **소형 태스크별 모델이 범용 LLM보다 3배** 더 사용
- IDC: AI 지출 **2029년 1.3조 달러** 전망
