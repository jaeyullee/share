# AI 모델 아키텍처 변천사 (2017-2026)

> Transformer부터 Nemotron까지, AI 모델 아키텍처가 어떻게 진화해왔는지 쉽게 정리한 문서.

## 전체 계통도: Transformer에서 뻗어나간 3개 분야

이 문서에 나오는 아키텍처들이 **전부 LLM은 아니다**. Transformer라는 공통 뿌리에서 3개 분야로 갈라졌다:

```
                Transformer (2017) ← 공통 뿌리
               /        |          \
        텍스트(LLM)    이미지(CV)    멀티모달
        /    \           |          /    \
     GPT   BERT       ViT       CLIP   GPT-4o
     LLaMA  T5     Diffusion   DALL-E  Gemini
     Mamba         Stable D.   Claude 4o
     MoE
     추론모델(o1, R1)
```

| 계통 | 설명 | 대표 모델 |
|---|---|---|
| **텍스트(LLM)** | 언어를 이해하거나 생성 | GPT, BERT, LLaMA, Mistral, Mamba, DeepSeek |
| **이미지(CV)** | 이미지를 이해하거나 생성 | ViT, Stable Diffusion, Midjourney |
| **멀티모달** | 텍스트+이미지+음성 등 여러 영역 통합 | CLIP, DALL-E, GPT-4o, Gemini |

> 아래 연대기에서 각 아키텍처가 어느 계통인지 표시해두었다.

## 2017: Transformer — 모든 것의 시작 `공통 뿌리`

**논문**: "Attention Is All You Need" (Vaswani 외, Google Brain)

### 핵심 혁신: Self-Attention (자기 주의 메커니즘)

이전의 AI(RNN/LSTM)는 문장을 **왼쪽에서 오른쪽으로 한 단어씩** 읽었다. 문장이 길어지면 앞쪽 단어를 까먹는 문제가 있었다.

Transformer는 **문장의 모든 단어를 동시에** 보면서, 각 단어가 다른 단어와 얼마나 관련 있는지를 계산한다.

> **비유**: RNN이 "소설을 처음부터 끝까지 한 줄씩 읽는 사람"이라면, Transformer는 "책 전체를 펼쳐놓고 형광펜으로 관련 있는 단어들을 서로 연결하는 사람"이다.

### 구조

```
입력 → [인코더: 문장 이해] → [디코더: 결과 생성] → 출력
         ↑ Self-Attention      ↑ Self-Attention
```

### 구현물

| 모델 | 용도 |
|---|---|
| 원본 Transformer | 기계 번역 (영→독 등) |

> 이후 나오는 **거의 모든 AI 모델**이 Transformer를 기반으로 한다.

## 2018-2019: 세 가지 갈래길 `LLM`

Transformer의 구조를 **어떻게 쓰느냐**에 따라 세 가지 파생이 나왔다. 이 셋 모두 **텍스트(LLM) 계통**이다.

### 1. GPT (디코더만 사용) — "글쓰기 전문가"

**논문**: GPT-1 (2018), GPT-2 (2019) — OpenAI, Radford 외

Transformer의 **디코더 부분만** 사용한다. 왼쪽→오른쪽으로만 읽으며 **다음 단어를 예측**하는 방식으로 학습한다.

> **비유**: 스마트폰 자동완성의 극강 버전. "오늘 날씨가" 다음에 올 단어를 예측하고, 그 다음, 그 다음을 계속 예측해서 글을 "생성"한다.

| 모델 | 파라미터 | 특징 |
|---|---|---|
| GPT-1 | 1.17억 | 사전학습 + 미세조정이 효과적임을 증명 |
| GPT-2 | 15억 | 미세조정 없이도 여러 과제 수행 가능 |

### 2. BERT (인코더만 사용) — "이해력 전문가"

**논문**: BERT (2018) — Google, Devlin 외

Transformer의 **인코더 부분만** 사용한다. 문장의 **양방향**(앞뒤 모두)을 보면서 빈칸을 맞추는 방식으로 학습한다.

> **비유**: "오늘 [빈칸] 좋다"에서 빈칸에 "날씨가"를 맞추는 빈칸 채우기 시험. 양쪽 문맥을 다 볼 수 있어서 **이해력**이 뛰어나다.

| 모델 | 파라미터 | 특징 |
|---|---|---|
| BERT-base | 1.1억 | NLP 벤치마크 석권 |
| BERT-large | 3.4억 | 검색 엔진, 감정 분석 등에 광범위 사용 |
| RoBERTa | 3.5억 | Facebook, BERT 학습법 개선 |
| DistilBERT | 6600만 | BERT의 경량화 버전 |

### 3. T5 (인코더+디코더 둘 다) — "만능 번역기"

**논문**: T5 (2019) — Google, Raffel 외

모든 NLP 과제를 **"텍스트 입력 → 텍스트 출력"**으로 통일한다.

> **비유**: 어떤 질문이든 "이 텍스트를 저 텍스트로 바꿔줘" 형태로 처리하는 만능 번역기.

| 모델 | 파라미터 | 특징 |
|---|---|---|
| T5-small ~ T5-11B | 6천만~110억 | 번역, 요약, 분류 등 모두 하나의 형식으로 |
| FLAN-T5 | 다양 | 명령어 튜닝 적용 버전 |

### 세 갈래 비교

```
             Transformer
            /     |      \
       인코더만  인코더+디코더  디코더만
        BERT       T5         GPT
      (이해 특화)  (만능)     (생성 특화)
```

## 2020: 스케일의 힘

### GPT-3 — "크면 된다" `LLM`

**논문**: "Language Models are Few-Shot Learners" — OpenAI, Brown 외

**1,750억 개** 파라미터. GPT-2의 100배 이상. 이 거대한 크기 덕분에 **예시 몇 개만 보여주면** 새로운 과제를 수행할 수 있게 되었다 (Few-shot Learning).

> **비유**: GPT-2가 "각 과목마다 따로 공부해야 하는 학생"이었다면, GPT-3는 "워낙 많이 읽어서 예시 2-3개만 보면 어떤 문제든 푸는 박학다식한 사람"이다.

| 구현물 | 용도 |
|---|---|
| OpenAI API | 다양한 애플리케이션의 AI 백엔드 |
| Codex | GPT-3를 코드에 특화시킨 버전 (→ GitHub Copilot) |

**같은 해 발표된 "스케일링 법칙" (Kaplan 외, OpenAI)**: 모델을 키우면 성능이 예측 가능하게 올라간다는 법칙을 수학적으로 증명했다.

### Vision Transformer (ViT) — "이미지도 Transformer로" `이미지(CV)`

**논문**: "An Image is Worth 16x16 Words" — Google, Dosovitskiy 외

이미지를 **16×16 픽셀 조각(패치)**으로 자르고, 각 조각을 "단어"처럼 취급해서 Transformer에 넣었다. 기존 이미지 AI의 왕좌였던 CNN(합성곱 신경망)에 필적하는 성능을 보였다.

> **비유**: 문장을 단어로 쪼개듯, 사진을 작은 타일로 쪼개서 "이 타일들 사이의 관계"를 파악하는 방식.

| 구현물 | 특징 |
|---|---|
| ViT | 원본 |
| DeiT | 데이터 효율적 버전 |
| Swin Transformer | 윈도우 기반 계층적 구조 |

## 2021: 멀티모달의 시작 `멀티모달`

"텍스트만" 다루던 AI가 **이미지, 코드** 등 다른 영역으로 확장되기 시작했다.

### DALL-E — "텍스트로 그림 그리기" `멀티모달`

**OpenAI** — 120억 파라미터 Transformer

텍스트 설명을 입력하면 **이미지를 생성**한다. 이미지를 작은 토큰으로 변환한 뒤, 텍스트 토큰과 이미지 토큰을 이어붙여서 GPT처럼 순차적으로 생성한다.

> **비유**: GPT가 단어를 하나씩 써서 글을 만들듯이, DALL-E는 그림 조각을 하나씩 찍어서 이미지를 만든다.

### CLIP — "이미지와 텍스트를 연결하는 다리" `멀티모달`

**OpenAI** — 4억 개 이미지-텍스트 쌍으로 학습

이미지와 텍스트를 **같은 공간**에 배치하는 모델. "고양이 사진"과 "고양이"라는 텍스트가 가까이 놓이도록 학습한다.

> **비유**: 사진과 캡션을 매칭하는 퀴즈를 4억 번 풀어서, 어떤 사진이든 어떤 설명과 가장 잘 맞는지 알아내는 능력을 갖췄다.

| 구현물 | 용도 |
|---|---|
| DALL-E | 텍스트→이미지 생성 |
| CLIP | 이미지 분류, 검색, 다른 모델의 부품 |
| Codex / GitHub Copilot | 자연어→코드 생성 |

## 2022: 대중화의 해

AI가 **일반 대중**에게 알려진 결정적인 해.

### InstructGPT / ChatGPT — "AI를 사람답게 만든 비법: RLHF" `LLM`

**논문**: "Training language models to follow instructions with human feedback" — OpenAI

GPT-3는 똑똑하지만 "도움이 되는 답변"을 하는 데는 서툴렀다. 해결책이 **RLHF (인간 피드백 강화학습)**이다:

```
1단계: 사람이 쓴 모범 답변으로 미세조정
2단계: "이 답변이 저 답변보다 낫다"는 인간 평가로 보상 모델 학습
3단계: 보상 모델을 이용해 AI를 강화학습으로 최적화
```

> **비유**: 원래 GPT-3는 "뭐든 아는 천재인데 말을 마구 하는 사람". RLHF는 그 천재에게 "상담원 교육"을 시킨 것이다. ChatGPT는 이렇게 훈련된 모델이다.

**ChatGPT** (2022.11): 2개월 만에 **1억 명** 사용자 — 역사상 가장 빠르게 성장한 소비자 앱.

### 디퓨전 모델 / Stable Diffusion — "노이즈에서 그림으로" `이미지(CV)`

**논문**: "Latent Diffusion Models" — Rombach 외 (2022)

DALL-E 1은 토큰을 순차 생성했지만, 디퓨전 모델은 **노이즈(잡음)를 점진적으로 제거**해서 이미지를 만든다.

```
순수한 노이즈 → [약간 덜 노이즈] → ... → [거의 완성] → 깨끗한 이미지
              (텍스트 설명이 각 단계를 안내)
```

> **비유**: TV 화면의 지직거림(노이즈)에서 시작해서, 텍스트 설명을 보면서 조금씩 선명하게 "현상"하는 것. 필름 사진 인화와 비슷하다.

| 구현물 | 특징 |
|---|---|
| Stable Diffusion | 오픈소스, Stability AI |
| DALL-E 2 | 디퓨전 방식으로 전환, OpenAI |
| Midjourney | 예술적 품질에 특화 |
| Imagen | Google |

### PaLM — "거대 모델의 창발적 능력" `LLM`

**Google** — 5,400억 파라미터

일정 규모를 넘어서면 갑자기 새로운 능력이 **"튀어나오는"** 현상(Emergent Abilities)을 보여줬다. 연쇄 추론(Chain-of-Thought), 코드 생성 등.

> **비유**: 물이 서서히 차가워지다가 0도에서 **갑자기** 얼듯이, 모델이 커지면 어느 시점에서 갑자기 새로운 능력이 나타난다.

### Chinchilla — "크기보다 데이터"

**DeepMind** — 700억 파라미터, 1.4조 토큰으로 학습

**핵심 발견**: 대부분의 거대 모델은 **학습 데이터가 부족**했다. 같은 컴퓨팅 예산이면, 모델을 키우는 것보다 **데이터를 더 많이 먹이는** 게 낫다.

> **비유**: "머리 크기가 큰 학생(큰 모델)이 책 10권 읽는 것"보다, "보통 머리 학생(작은 모델)이 책 100권 읽는 것"이 더 성적이 좋다.

이 발견은 이후 모든 모델 설계를 바꿔놓았다 (특히 LLaMA).

## 2023: 오픈소스 폭발과 MoE `LLM`

### GPT-4 — "비공개 왕좌" `LLM` `멀티모달`

**OpenAI** (2023.3) — 구조 비공개 (MoE 구조로 추정, 총 ~1.7조 파라미터)

추론, 지시 수행, 멀티모달(이미지 입력)에서 대폭 향상. 미국 변호사 시험 상위 10%.

| 구현물 | 용도 |
|---|---|
| ChatGPT Plus | 유료 구독 |
| Microsoft Copilot | Office, Bing 등 |
| API | 수천 개 앱의 백엔드 |

### LLaMA — "오픈소스 빅뱅" `LLM`

**Meta** (2023.2) — 7B, 13B, 33B, 65B 파라미터

Chinchilla의 교훈을 적용: **작지만 잘 훈련된** 오픈 모델. LLaMA 65B가 GPT-3.5에 필적하는 성능을 보여주면서, **오픈소스 AI 생태계가 폭발**했다.

> **비유**: 명문대가 모든 교재와 커리큘럼을 무료 공개한 것. 누구나 이 위에 자기만의 모델을 만들 수 있게 되었다.

| 파생 모델 | 특징 |
|---|---|
| Alpaca (Stanford) | LLaMA + 명령어 튜닝 |
| Vicuna | ChatGPT 대화 데이터로 튜닝 |
| LLaMA 2 (2023.7) | 진짜 오픈 라이선스 |
| LLaMA 3 (2024) | 8B, 70B, 405B — 오픈소스 최강 |

### Mistral / Mixtral — "오픈소스 MoE" `LLM`

**Mistral AI** (프랑스 스타트업)

- **Mistral 7B** (2023.9): Sliding Window Attention으로 LLaMA 2 13B에 필적하는 성능을 절반 크기로 달성.
- **Mixtral 8×7B** (2023.12): 오픈소스 최초의 본격적 **MoE 모델**.

### Mixture of Experts (MoE)란?

일반 모델(Dense)은 **모든 파라미터가 매번 작동**한다. MoE는 여러 "전문가 네트워크"를 두고, 각 입력마다 **일부 전문가만 선택**해서 작동시킨다.

```
입력 토큰 → [라우터: 어떤 전문가를 쓸까?]
              ↓
         전문가1  전문가2  전문가3  전문가4  전문가5  전문가6  전문가7  전문가8
              ↓      ↓
         [2개만 활성화] → 출력
```

> **비유**: 종합병원에 8명의 전문의가 있다. 환자(토큰)가 오면 가장 적합한 2명만 진료한다. 전체 지식(총 파라미터)은 방대하지만, 매번 드는 비용(계산량)은 적다.

| MoE 모델 | 전문가 수 / 활성 | 총 파라미터 |
|---|---|---|
| Mixtral 8×7B | 8개 중 2개 활성 | 467억 (활성 ~130억) |
| GPT-4 (추정) | 8개 중 2개 | ~1.7조 |
| Grok-1 (xAI) | MoE | 3,140억 |
| DeepSeek-V2 | 160개 중 6개 | 2,360억 (활성 210억) |

## 2024: 아키텍처 다양화

Transformer가 유일한 선택지가 아니게 되었다.

### Mamba / State Space Models (SSM) — "Transformer의 대안" `LLM(대안 아키텍처)`

**논문**: "Mamba: Linear-Time Sequence Modeling with Selective State Spaces" — Gu & Dao (2023.12)

Transformer의 Self-Attention은 문장이 길어지면 계산량이 **제곱으로** 늘어난다 (O(n²)). Mamba는 이를 **선형**(O(n))으로 줄였다.

> **비유**: Transformer는 교실의 모든 학생이 서로 대화하는 방식(n명이면 n²개의 대화). Mamba는 컨베이어 벨트 위에 스마트 필터를 놓고, 중요한 것만 기억하면서 흘려보내는 방식.

### Transformer vs Mamba/SSM 비교

| 항목 | Transformer | Mamba/SSM |
|---|---|---|
| 계산 복잡도 | O(n²) — 길이에 제곱 비례 | O(n) — 길이에 선형 비례 |
| 긴 문맥 처리 | 비싸다 (Flash Attention 등 트릭 필요) | 자연스럽게 효율적 |
| 학습 병렬화 | 뛰어남 | 좋음 (parallel scan) |
| 문맥 내 학습 | 강함 (어떤 과거 토큰이든 참조 가능) | 약함 (압축된 상태만 보유) |
| 추론 속도 | KV 캐시가 문맥 길이만큼 증가 | 일정한 메모리 상태 |
| 현재 품질 | 최고 수준 | 경쟁적이나 초대형에선 아직 밀림 |

**하이브리드 접근**: 결국 "둘 다 쓰자"가 트렌드.

| 구현물 | 특징 |
|---|---|
| Mamba-1, Mamba-2 | 순수 SSM |
| Jamba (AI21) | Mamba + Transformer + MoE 하이브리드 |
| Nemotron-H (NVIDIA) | Transformer + Mamba 하이브리드 (Hymba) |
| RWKV-5/6 | 선형 어텐션 기반 RNN-Transformer 하이브리드 |

### RWKV — "RNN의 부활" `LLM(대안 아키텍처)`

Transformer의 병렬 학습 장점과 RNN의 효율적 추론 장점을 결합한다. 학습 시에는 Transformer처럼, 추론 시에는 RNN처럼 동작한다.

| 버전 | 별칭 | 최대 크기 |
|---|---|---|
| RWKV-4 | — | 14B |
| RWKV-5 | Eagle | 7B |
| RWKV-6 | Finch | 14B+ |

### GPT-4o — "진짜 멀티모달" `멀티모달`

**OpenAI** (2024.5)

이전 모델들은 텍스트 모델에 이미지/음성 기능을 "붙인" 것이었다. GPT-4o는 텍스트, 이미지, 음성을 **하나의 신경망**에서 처리한다.

> **비유**: 이전 = 통역사 3명이 각자 맡은 언어를 번역해서 전달. GPT-4o = 3개 국어를 모국어처럼 하는 1명.

### Claude 3 — "안전과 성능의 균형" `LLM` `멀티모달`

**Anthropic** (2024.3) — Haiku / Sonnet / Opus 3단계

200K 토큰 컨텍스트, 이미지 이해 가능. Constitutional AI(헌법 AI) 방식으로 안전성 확보.

### Gemini — "100만 토큰 컨텍스트" `LLM` `멀티모달`

**Google DeepMind** — Gemini 1.5 Pro (2024.2)

MoE 구조로 **100만 토큰**(나중에 200만) 컨텍스트 윈도우 달성. 코드베이스 전체, 긴 동영상, 책 한 권을 통째로 처리 가능.

## 2025: 추론 혁명 `LLM`

2025년의 핵심 키워드: **"더 오래 생각하게 하자" (Test-time Compute Scaling)**

### 추론 모델이란?

기존 LLM은 질문을 받으면 **즉시** 대답한다. 추론 모델은 답하기 전에 **머릿속으로 단계별 사고(Chain-of-Thought)**를 한다.

> **비유**: 일반 LLM = 시험에서 바로 답을 적는 학생. 추론 모델 = 연습장에 풀이 과정을 쓰면서 검산까지 하고 답을 적는 학생.

이것은 새로운 스케일링 축이다:
- 이전: 모델을 **키우면** 성능 향상 (학습 시 컴퓨팅 ↑)
- 추론 모델: 모델이 **더 오래 생각하면** 성능 향상 (추론 시 컴퓨팅 ↑)

### OpenAI o1 / o3

| 모델 | 시기 | 특징 |
|---|---|---|
| o1 | 2024.9 | 최초 추론 모델. 수학/코드/과학에서 큰 향상 |
| o3 | 2024.12 발표 | o1 대비 대폭 향상. ARC-AGI 25.2% (o1은 ~5%) |

### DeepSeek R1 — "오픈소스 추론의 충격"

**DeepSeek** (중국, 2025.1)

순수 **강화학습(GRPO)**만으로 추론 능력을 발현시켰다. 사람이 쓴 풀이 과정 예시 없이, AI가 **스스로** "단계별로 생각하면 정답률이 올라간다"를 깨달았다.

> **비유**: 선생님이 풀이법을 가르친 게 아니라, "정답 맞추면 상 준다"고만 했더니 학생이 스스로 풀이 과정을 발명한 것.

| 모델 | 크기 | 특징 |
|---|---|---|
| DeepSeek-V3 | 6,710억 MoE (활성 370억) | 기반 모델 |
| DeepSeek-R1 | 위와 동일 | 추론 특화 |
| R1-distill 시리즈 | 1.5B ~ 70B | 소형 증류 버전 |

**충격 포인트**: 학습 비용 **약 560만 달러** (서방 동급 모델의 1/100). 완전 오픈 웨이트.

## 2026: 현재 최전선

### Nemotron (NVIDIA)

NVIDIA가 만든 언어 모델 패밀리. GPU 회사가 **자체 AI 모델**을 만든다는 점에서 주목.

**핵심 전략**: 큰 모델로 **합성 데이터**(인공 학습 데이터)를 만들고, 그 데이터로 작은 모델을 훈련시킨다.

| 모델 | 크기 | 특징 |
|---|---|---|
| Nemotron-4 15B | 150억 | 8조 토큰 학습, NVIDIA 하드웨어 최적화 |
| Nemotron-4 340B | 3,400억 | Base/Instruct/Reward 3종 |
| LLaMA-3.1-Nemotron-70B | 700억 | Meta LLaMA에 NVIDIA RLHF 파이프라인 적용 |
| **Nemotron-H** | — | **Transformer + Mamba 하이브리드** (Hymba 아키텍처) |

> **Nemotron-H가 중요한 이유**: GPU를 만드는 회사(NVIDIA)가 Transformer **이후**의 아키텍처를 탐색하고 있다는 신호.

### Claude 4.5 / 4.6 Opus

현재 이 대화에 사용되고 있는 모델. **100만 토큰 컨텍스트** 윈도우 (Claude 3의 5배).

## 핵심 트렌드 요약

### 6가지 스케일링 시대

```
2020  파라미터 스케일링     "모델을 키우자"           (GPT-3)
  ↓
2022  데이터 스케일링       "데이터를 더 먹이자"       (Chinchilla)
  ↓
2023  효율 스케일링         "똑같은 비용으로 더 잘"    (MoE, LLaMA)
  ↓
2024  추론 스케일링         "더 오래 생각하게 하자"    (o1, DeepSeek R1)
  ↓
2025  컨텍스트 스케일링     "더 많이 한번에 보게 하자"  (1M+ 토큰)
  ↓
2026  하이브리드 아키텍처   "Transformer + SSM 결합"   (Nemotron-H)
```

### 5대 메가 트렌드

1. **추론 혁명**: 모델이 "더 오래 생각하면" 더 정확해진다는 새로운 패러다임
2. **MoE 일반화**: 거대 모델의 기본 구조가 Dense → MoE로 전환
3. **Transformer 이후 탐색**: Mamba/SSM, 하이브리드 아키텍처가 부상
4. **오픈소스 민주화**: LLaMA → Mistral → DeepSeek로 이어지는 오픈 생태계
5. **네이티브 멀티모달**: 텍스트·이미지·음성을 하나의 모델에서 처리
