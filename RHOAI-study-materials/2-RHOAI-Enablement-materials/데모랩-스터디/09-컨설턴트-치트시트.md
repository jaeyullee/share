## 2. 꼭 외울 기술 스택 한 장

- **서빙**: KServe(서빙 추상화) + **vLLM**(LLM 런타임, OpenAI 호환) — RHOAI 3 표준. → [05-vLLM-추론엔진-핵심정리](../../4-etc-AI-materials/read/05-vLLM-추론엔진-핵심정리.md)
- **분산추론**: **llm-d** `LLMInferenceService` + 3 스코어러(prefix-cache/queue/active). → [01-분산추론과-llm-d](../../3-RHOAI-Personal-materials/read/01-분산추론과-llm-d.md)
- **게이트웨이**: **RHCL** + Gateway API + Authorino(인증) + Limitador(rate limit) + TLS.
- **앱 미들웨어**: **Llama Stack**(5 API: 추론/에이전트/RAG/안전/도구) `LlamaStackDistribution`(:8321). → [02-Llama-Stack-핵심](02-Llama-Stack-핵심.md)
- **통합**: **MCP** 서버/클라이언트 + ToolHive + MCPToolConfig(allowlist) + Registry. → [03-MCP-핵심](03-MCP-핵심.md)
- **RAG**: 벡터 DB(pgvector/Milvus/Redis/ES) + 임베딩(MiniLM/Nomic/mpnet) + 청킹/하이브리드검색/인용. → [01-RAG-아키텍처-핵심정리](../../4-etc-AI-materials/01-RAG-아키텍처-핵심정리.md)
- **안전·평가·관찰성**: Shields(Llama Guard 3, S1~S7) / Evals(결정론+LLM-judge) / Langfuse(traces).
- **배포**: ArgoCD GitOps, Validated Patterns(`values-global/secret.yaml`), Kustomize 게이팅.
- **인프라 전제**: NVIDIA GPU Operator + NFD, S3(MCGW/ODF/MinIO), (Serverless/Service Mesh).
- **데이터/MLOps**: Model Registry(`rhoai-model-registries`), Pipelines(Tekton/Elyra), Training Operator+Ray, TrustyAI, Feature Store. → [03-rhoai-mlops-knowledge](../../3-RHOAI-Personal-materials/03-rhoai-mlops-knowledge.md)

## 3. 자주 받을 질문 & 답 (FAQ)

- **"파인튜닝 vs RAG?"** → 지식 주입은 RAG(싸고 빠름·출처추적), 행동/스타일 변경은 파인튜닝. 보통 RAG 먼저.
- **"GPU 몇 장 필요?"** → 모델 크기·동시성·SLA로 산정. 공유는 MIG/MPS/Time-slicing. → [[0-Important/01-LLM-필요VRAM-계산법]], [[GPU-공유전략-MIG-MPS-Timeslicing]]
- **"성능이 안 나와요"** → throughput vs tail latency 구분. 캐시 인식 라우팅(llm-d)·KV 캐시 점검. GuideLLM 벤치마크.
- **"보안/멀티테넌시?"** → 네임스페이스 격리 + 게이트웨이 토큰(Authorino) + rate limit(Limitador) + 내부 노출.
- **"벡터 DB 뭘 쓰죠?"** → 기존 PG면 pgvector, 전용·확장이면 Milvus, 저지연 Redis, 대규모 ES.
- **"할루시네이션?"** → RAG+인용, 검색품질, Shields, Evals 회귀검증.
- **"어떻게 배포·이관?"** → GitOps(ArgoCD)·Validated Pattern·PoC template로 코드화.

## 5. 흔한 함정 (enabler 주의)

- 데모 일부 **alpha/WIP**(RHOAI 3 MaaS/관찰성 등) → 고객 환경 **GA 버전**으로 기능 가용성 재확인.
- 복잡 CRD는 **UI 배포 실패** 가능 → YAML/GitOps.
- RHOAI는 **모델 저장소가 아님** → S3(MCGW/MinIO) + Data Connection 별도.
- GPU MachineSet 자동생성은 **클라우드(AWS) 전제** → 온프레는 노드 사전준비.
- 토큰/시크릿은 **외부화**(values-secret/Vault), Git에 올리지 말 것.
- 에이전트 PoC는 안전/평가/관찰성 없이 "동작"만 보여주면 프로덕션 갭 큼.
