# W3Schools — Data Science Tutorial

- **링크**: https://www.w3schools.com/datascience/default.asp
- **분류**: References (학습 자료)
- **한 줄**: Python 기반 데이터 사이언스 입문 튜토리얼, "Try it Yourself" 인터랙티브 코드 에디터 제공.

## 학습 경로

초심자 대상. 데이터 기반 의사결정을 돕는 데이터 사이언스를 Python 실습으로 학습.

## 주요 모듈

- **기초**: DS 소개, 데이터/DB 테이블 이해, Python 기본, DataFrame 연산, 데이터 준비·분석 함수
- **수학 기초**: 선형 함수와 그래프, 기울기·절편 계산
- **통계 분석**: 백분위수, 표준편차, 분산, 상관관계·상관행렬, 상관 vs 인과
- **고급**: 선형 회귀 모델링, 회귀 테이블, 계수 해석, P-value, R-squared, 실전 케이스 스터디

## 특징

pandas·matplotlib·scipy 라이브러리를 쓰는 인터랙티브 코드 에디터. 이론보다 실습 예제 중심. 수료 시험으로 마무리.

## 워크숍 맥락

ML 이전 단계인 데이터 다루기·기초 통계·회귀를 빠르게 훑기 좋은 입문 자료.
