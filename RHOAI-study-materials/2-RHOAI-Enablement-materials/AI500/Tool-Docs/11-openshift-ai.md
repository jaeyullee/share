# Red Hat OpenShift AI (RHOAI) — 공식 문서

- **링크**: https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/2-latest
- **분류**: Tool-Docs / AI
- **한 줄**: OpenShift 위에서 AI/ML 모델을 개발·학습·서빙·모니터링하는 Red Hat의 통합 MLOps 플랫폼 공식 문서.

## 무엇인가

RHOAI(self-managed)는 데이터 사이언티스트·ML 엔지니어가 예측·생성 AI 모델을 전 생애주기에 걸쳐 다루도록 지원하는 엔터프라이즈 플랫폼. Open Data Hub의 다운스트림 제품.

## 주요 기능 영역

- **Workbenches** — Jupyter 기반 노트북 개발 환경
- **Model Serving** — KServe(단일 모델)·ModelMesh(다중 모델), vLLM 등 런타임
- **Data Science Pipelines** — Kubeflow Pipelines 기반 파이프라인
- **분산 학습** — Ray, CodeFlare, Kueue 기반 분산 워크로드
- **Model Registry** — 모델 버전 관리
- **Monitoring & TrustyAI** — 편향·drift·설명가능성 모니터링
- **GPU/가속기** — Accelerator Profile, MIG 슬라이싱
