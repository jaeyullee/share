# Gitea — 공식 문서

- **링크**: https://docs.gitea.com/
- **분류**: Tool-Docs / DevOps
- **한 줄**: Go로 작성된 경량 셀프호스팅 Git 서비스(올인원 개발 플랫폼).

## 무엇인가

"the easiest, fastest, and most painless way of setting up a self-hosted Git service." Linux·macOS·Windows, 다중 아키텍처에서 동작.

## 주요 기능

- 저장소 호스팅 (커밋 히스토리·코드 브라우징·협업)
- Pull Request·코드 리뷰
- **Gitea Actions** — GitHub Actions 호환 CI/CD
- 이슈 추적 (마일스톤·할당·의존성)
- 패키지 레지스트리 (npm, PyPI, Maven 등 20+ 포맷)
- 경량 설계 (소규모 팀 권장 2 CPU/1GB RAM)

## 문서 범위

설치·관리·사용, 개발 실천, 시스템 요구사항, 기술 구성(Chi 프레임워크, XORM ORM, 다중 DB).
