# 요약 ④ 사용 도구 한눈에 (Tool-Docs 20개)

> 워크숍에서 쓰는 도구 20종을 **MLOps 파이프라인 흐름**에 따라 한 장으로 정리. 상세는 각 개별 노트 참조.

## 파이프라인 흐름으로 본 도구 지도

```
데이터/피처 → 개발·학습 → 패키징·품질 → 배포(GitOps) → 서빙 → 모니터링
  Feast       KFP/DVC      Black/Flake8    Argo CD     KServe    Grafana
              ModelScan    pytest/Sonar    Tekton      OpenVINO  TrustyAI
                           KubeLinter/Helm  Gitea
```

## 한 줄 정리

AI 도구는 **데이터→학습→서빙→신뢰성**(Feast·KFP·KServe·TrustyAI), DevOps 도구는 **소스→CI 품질게이트→GitOps 배포→관찰**(Gitea·Tekton·Argo CD·Grafana) 축을 담당한다. 두 축이 RHOAI(11) 위에서 만나 MLOps E2E를 이룬다. 개념 배경은 [[요약-02-MLOps-방법론-실전]], 실무 적용은 [[요약-03-OpenShift-AI-실무]] 참조.
