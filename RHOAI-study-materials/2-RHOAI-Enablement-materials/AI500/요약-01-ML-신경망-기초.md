# 요약 ① ML·신경망 기초 학습

> References 중 **ML/신경망의 개념과 직관**을 쌓는 자료 4종 요약. 상세는 각 개별 노트 참조.

## 학습 흐름

데이터 다루기 → 신경망 이론 → 직접 실험 → 구조 시각화 순으로 기초 직관을 쌓는 자료들이다.

## 1. 데이터·통계 기초 — W3Schools Data Science

- Python(pandas·matplotlib·scipy) 기반 **데이터 사이언스 입문 튜토리얼**, "Try it Yourself" 인터랙티브 코드 에디터.
- 데이터/DataFrame 다루기 → 기초 통계(백분위·표준편차·상관) → **선형 회귀**(계수·P-value·R²)까지.
- ML 이전 단계인 데이터·통계·회귀를 빠르게 훑기 좋음.

## 2. 신경망 이론 — 3Blue1Brown "Neural networks" (영상)

- 신경망 구조, **경사하강법**, **역전파**, 트랜스포머 **attention**까지 직관적 애니메이션으로 설명.
- 신경망 입문자에게 전체 재생목록 추천(특히 앞 4편). 현대 LLM/챗봇의 근간 개념.

## 3. 직접 실험 — TensorFlow Playground

- 브라우저에서 소규모 신경망을 만지며 학습 과정을 **실시간 시각화**.
- 조정 파라미터: learning rate, activation(ReLU/Tanh/Sigmoid), regularization(L1/L2), hidden layer 수, 데이터 노이즈 등.
- **하이퍼파라미터가 학습에 미치는 영향**을 손으로 체감.

## 4. 구조 시각화 — CNN Explainer

- 합성곱 신경망(CNN)의 데이터 흐름을 인터랙티브 시각화(Georgia Tech, IEEE TVCG 2020 논문).
- 핵심 연산: **Convolution(피처 검출) → ReLU(비선형) → Pooling(차원 축소) → Softmax(확률 출력)**.
- 추상적 수학 연산을 관찰 가능한 현상으로 변환.

## 한 줄 정리

이론(3Blue1Brown) ↔ 실험(TF Playground) ↔ 구조(CNN Explainer)를 오가며 신경망 직관을 만들고, W3Schools로 그 밑단의 데이터·통계 토대를 다진다.
