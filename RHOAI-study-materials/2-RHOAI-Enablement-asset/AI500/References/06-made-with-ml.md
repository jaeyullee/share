# Made With ML

- **링크**: https://madewithml.com/
- **분류**: References (학습 자료)
- **한 줄**: ML과 소프트웨어 엔지니어링을 결합해 프로덕션 ML 애플리케이션을 설계·개발·배포·반복하는 법을 가르치는 Anyscale의 교육 플랫폼.

## 대상

전문 개발자(SW/인프라 엔지니어, 데이터 사이언티스트), 산업 실무 역량을 원하는 신규 졸업생, ML 기초가 필요한 프로덕트/리더십 직군. (선수지식: Python + 기초 ML)

## 커리큘럼 (8개 섹션)

1. **Design** — 셋업, 프로덕트 설계, 시스템 아키텍처
2. **Data** — 준비, 탐색, 전처리, 분산 데이터 처리
3. **Model** — 학습, 실험 추적, 튜닝, 평가, 서빙
4. **Development** — 스크립팅, CLI 도구
5. **Utilities** — 로깅, 문서화, 스타일링, pre-commit
6. **Testing** — 코드·데이터·모델 검증
7. **Reproducibility** — 버전 관리
8. **Production** — 잡, 서비스, CI/CD, 모니터링, 데이터 엔지니어링

## 강조점

"first principles 이해", SW 엔지니어링 베스트 프랙티스, 확장 가능한 Python 워크플로, MLOps 통합, 프로덕션 배포 패턴.
