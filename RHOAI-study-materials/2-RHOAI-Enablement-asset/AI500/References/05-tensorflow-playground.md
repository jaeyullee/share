# TensorFlow Playground

- **링크**: https://playground.tensorflow.org/
- **분류**: References (학습 자료)
- **한 줄**: 브라우저에서 소규모 신경망을 직접 조작하며 학습 과정을 실시간 시각화하는 인터랙티브 도구.

## 조정 가능한 파라미터

- **Learning rate**: 학습 속도 (0.00001 ~ 10)
- **Activation**: ReLU, Tanh, Sigmoid, Linear
- **Regularization**: None, L1, L2 (비율 조정 가능)
- **Problem type**: Classification / Regression
- **네트워크 구조**: hidden layer 추가/제거
- **데이터 설정**: train/test 비율, 노이즈, batch size
- **Features**: 입력 피처 선택

## 교육적 가치

성공으로 이어지는 연결은 강화하고 실패하는 연결은 약화시키며 신경망이 학습하는 과정을 보여준다. 색상 시각화(주황=음수, 파랑=양수)로 가중치·예측·신뢰도를 실시간 관찰 → 추상적 신경망 개념을 체감 가능하게 만듦.
