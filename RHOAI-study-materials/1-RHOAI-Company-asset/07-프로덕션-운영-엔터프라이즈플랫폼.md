# Manage AI in production with an enterprise platform 정리

> 원본: `Manage AI in production with an enterprise platform.PDF` — Red Hat AI 포트폴리오 종합 + 4대 제품 + 파트너 생태계 + 고객사례.
> 상위 맥락: [[00-인덱스]]

---

## 1. 배경

- AI가 비즈니스 모델 재편. 많은 조직이 아직 일상 운영에 미통합.
- 공개 AI 서비스 vs 온프렘 전용 인프라 사이 트레이드오프. 데이터 프라이버시·규제 → 자체 **MaaS 제공자**화 또는 소버린 AI 클라우드.
- 도메인 특화 모델은 응답 정교화하나 커스터마이징에 컴퓨트·데이터·전문성 비용. 모델·에이전트·데이터 위치가 HW·프라이버시·거버넌스 결정에 영향.

## 2. Red Hat AI 포트폴리오 (4종)

- **Red Hat AI Enterprise** — 효율적 배포·확장(anywhere).
- **Red Hat AI Inference Server** — LLM 최적화 추론.
- **Red Hat OpenShift AI** — 분산 Kubernetes 환경.
- **Red Hat Enterprise Linux AI** — 개별 Linux 서버.
- + **파트너 생태계**(검증·인증 제품·서비스).

## 3. 4대 역량

### (1) 고성능 추론
- 예측 AI: 단일/멀티모델 서빙(수백 모델 통합), vLLM·OpenVINO·NVIDIA NIM·Triton·Caikt·TGIS 런타임.
- Gen AI: **vLLM**(메모리·속도·GPU 효율) + **llm-d**(클러스터 전반 자원 최적화) → **SLO 충족**.
- 최적화·검증 3rd party 모델(벤치마크·정확도 평가, SafeTensor, 배포 커맨드). 자체 최적화도 가능.

### (2) 모델 커스터마이징
- 데이터 인제스트·전처리(정형/비정형), **SDG Hub**.
- 계층적: prompt design → **RAG**(검증가능 사내 소스) → fine-tuning(full ~ PEFT).
- 셀프서비스 IDE·OSS 프레임워크, SDG Hub~Training Hub 전주기 거버넌스.

### (3) 에이전트 AI
- 표준화 통합·오케스트레이션: **Llama Stack API** 엔터프라이즈 구현(pluggable, 일관된 tool call).
- **MCP** 거버넌스 툴 연결(+MCP 게이트웨이 로드맵), AI 안전·컴플라이언스 백본.
- **AI hub**(플랫폼 엔지니어 자산 거버넌스) + **gen AI studio**(AI 엔지니어 실험).

### (4) 어디든 배포
- train/tune/deploy/run을 비즈니스에 맞는 곳에서. MLOps·LLMOps(자동화·모니터링·거버넌스·자원할당·보안). 온프렘·**air-gapped** → 디지털 주권.

## 4. 제품별 포지셔닝

- **Inference Server** — vLLM 코어. 모델 레포 + LLM compressor. 모든 가속기·k8s·Linux·엣지.
- **AI Enterprise** — OpenShift 기반 통합. 모델+앱 라이프사이클 통합, IDE(Jupyter)·PyTorch·워크벤치, 카탈로그/레지스트리(검증모델·MCP). MLOps/genAIOps/AgentOps 통합. vLLM+llm-d, NVIDIA·AMD·Intel + OEM. drift·guardrails. air-gapped.
- **RHEL AI** — immutable 어플라이언스(image mode for RHEL), OS+앱 부팅 이미지. PyTorch·드라이버·가속기(NVIDIA/Intel/AMD). vLLM + LLM compressor. Day 1 운영.
- **OpenShift AI** — 예측+생성 라이프사이클. self-managed 또는 managed 클라우드 서비스. RAG·fine-tuning, AI 파이프라인·레지스트리, vLLM 멀티 GPU 스케일, llm-d, 관찰성(drift·bias)·guardrails.

## 5. 파트너 생태계

- **HW/가속기 벤더**: NVIDIA·AMD·Intel(검증·인증), OEM(Dell·Lenovo). **NVIDIA GPU Operator** 자동화.
- **모델 제공자**: Meta(Llama)·IBM(Granite)·Mistral 검증·최적화 → HF.
- **클라우드**: AWS·Azure·Google Cloud·IBM Cloud.
- **ISV / GSI**: AI factory 등 소버린·스케일 솔루션.

## 6. 고객사례 (4곳 상세)

- **RTLZWEI** (독일 방송) — IT sprawl 통합, vLLM 영상 전사·번역, 온프렘 파인튜닝으로 **단어오류율 33%↓**, 클릭 몇 번에 테스트 환경.
- **DenizBank** (Intertech) — 데이터과학자 **120명+** 자율성·표준, 자동 환경구축, **GPU slicing**.
- **Turkish Airlines** (Turkish Technology) — **60+ 라이브 모델**, 배포시간 절반, 워크스페이스 시간→분, 동적가격·지상시간·사기탐지. **$1억+** 목표.
- **Red Hat 내부** — IT 지원 AI 4종, **$500만 비용회피**(10개월 $150만), 월 3만 케이스.
